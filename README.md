# 姜湉个人网站

这是姜湉的个人学术与教育实践网站，采用原生 HTML、CSS 和 JavaScript 构建，可直接部署到 GitHub Pages。

## 网站栏目

- 首页与个人简介
- 专业文章
- 项目与研究
- 课程与讲座
- 活动与足迹
- 著作与成果
- 关于我
- 联系我

## 本地预览

直接打开 `index.html`，或在仓库目录启动任意静态文件服务器。

## 内容更新

- 页面内容：`index.html`
- 视觉样式：`style.css`
- 菜单、筛选与滚动交互：`script.js`
- 图片素材：`assets/`

python -m unittest discover -s tests -v
